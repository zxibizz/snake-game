# Змейград (snake-game)

Змейки на арене для браузера: без рекламы, одному без интернета или вместе по сети. Сайт — `https://snake.games.bubas.cc`.

## Режимы

- **Одному** — мир считается на устройстве, работает офлайн (PWA):
  - лёгкий — добрые боты, после проигрыша можно продолжить, край арены отталкивает;
  - средний — одна жизнь, боты иногда подрезают;
  - сложный — одна жизнь, боты охотятся, окружают и ускоряются.
- **Вместе** — комната с кодом из 4 цифр (или ссылка `?room=1234`), до 8 игроков, сверху боты выбранной сложности:
  - «Команда» — свои змейки проходят друг сквозь друга, все против ботов;
  - «Все против всех» — подрезать можно и друг друга.
  После проигрыша в комнате всегда можно продолжить.

Управление на сенсорном экране — джойстик от точки касания, кнопка-молния — ускорение. На компьютере — мышь или стрелки, пробел — ускорение.

## Устройство

| Путь | Что |
|---|---|
| `public/core.js` | общая логика мира: змейки, еда, боты, столкновения. Без DOM и сети |
| `public/client.js` | отрисовка, управление, меню; одиночная игра и сетевой клиент |
| `public/sw.js` | офлайн-кэш |
| `server/server.js` | статика + комнаты по WebSocket `/ws`, 40 шагов мира и 20 снимков в секунду |
| `server/ws.js` | минимальный WebSocket (RFC 6455), без зависимостей |

Сервер авторитетный: клиент шлёт только угол и ускорение, получает бинарные снимки (головы змей, масса, изменения еды) и достраивает тела сам. Около 4–5 КБ/с на игрока. Ограничения: 20 комнат, 8 игроков в комнате, 120 соединений; пустая комната закрывается через минуту.

## Разработка

```bash
node server/server.js        # http://localhost:8080
node --test test/            # тесты мира и сервера
```

Node 22+, зависимостей нет.

## Выпуск

1. После правки файлов в `public/` поднять `VERSION` в `public/sw.js` и `public/client.js` — иначе устройства останутся на старой версии из кэша.
2. Тег `vX.Y.Z` → GitHub Actions собирает `ghcr.io/zxibizz/snake-game:X.Y.Z`, Flux в кластере лаба подхватывает новый тег сам.

# Змейград (snake-game)

Змейки на арене для браузера: без рекламы, одному без интернета или вместе по сети. Сайт — `https://snake.games.bubas.cc`.

## Режимы

На арене всегда сто змей: игроки и боты. С первой секунды среди них есть гиганты длиной в несколько тысяч — путь с последнего места в первую десятку и к короне занимает всю игру.

- **Одному** — мир считается на устройстве, работает офлайн (PWA):
  - лёгкий — боты ускоряются, обгоняют и подрезают друг друга и игрока (на игрока — не больше одного сразу, первые 10 секунд не трогают); после проигрыша можно продолжить с половиной длины, край арены отталкивает;
  - средний — одна жизнь, боты смелее и хитрее, выскакивают из ловушек;
  - сложный — одна жизнь, боты охотятся стаей (до четырёх на игрока) и окружают.
- **Вместе** — комната с кодом из 4 цифр (или ссылка `?room=1234`), до 8 игроков, остальные места до сотни — боты выбранной сложности:
  - «Команда» — свои змейки проходят друг сквозь друга, все против ботов;
  - «Все против всех» — подрезать можно и друг друга.
  После проигрыша в комнате всегда можно продолжить.

Управление на сенсорном экране — джойстик от точки касания, кнопка-молния — ускорение. На компьютере — мышь или стрелки, пробел — ускорение.

## Что держит интерес

- **Звания по длине** за одну игру: Малыш → Червячок → … → Анаконда → Змей Горыныч → Легенда арены, с полоской до следующего.
- **Место в таблице** из ста змей, бонусы за первую полусотню, десятку, тройку и первое место; у самой длинной змеи — корона.
- **Звёзды и уровни** между играми: за еду, победы, звания, места и задания. Уровень открывает раскраски — 12 палитр (радуга, закат, океан, павлин…): тело из бусин-чешуек, по две бусины на цвет, последняя палитра на 20 уровне. При ускорении по бусинам от головы к хвосту бежит волна свечения в их цветах. Боты ползают и в закрытых раскрасках — видно, к чему стремиться.
- **Задания дня** — три штуки (съесть, победить, попасть в топ, найти пир, отомстить…), сложность растёт с уровнем; за все три — бонус.
- **Золотой пир** раз в минуту появляется где-то на арене — стрелка у края экрана ведёт к нему, туда же сползаются боты.
- **Месть**: после проигрыша обидчик подсвечен и к нему ведёт стрелка, за победу над ним — бонус.
- **Серии побед** и победы над гигантами — крупной надписью.

Прогресс хранится в `localStorage` устройства (ключ `zmeigrad`).

## Устройство

| Путь | Что |
|---|---|
| `public/core.js` | общая логика мира: змейки, еда, боты, пир, столкновения, раскраски и звания. Без DOM и сети |
| `public/client.js` | отрисовка, управление, меню, звёзды, уровни и задания; одиночная игра и сетевой клиент |
| `public/sw.js` | офлайн-кэш |
| `server/server.js` | статика + комнаты по WebSocket `/ws`, 40 шагов мира и 20 снимков в секунду, зона видимости игрока |
| `server/ws.js` | минимальный WebSocket (RFC 6455), без зависимостей |

Сервер авторитетный: клиент шлёт только угол и ускорение. Каждому игроку сервер шлёт только змей, у которых хоть часть тела ближе 2300 к его голове, и еду из клеток 1000×1000 в радиусе 2600; раз в секунду — таблицу лидеров и мини-карту по всей арене. Тела клиент достраивает сам по движению голов. Около 20–25 КБ/с на игрока. Ограничения: 8 комнат (комната — сотня змей, около 5 % ядра), 8 игроков в комнате, 120 соединений; пустая комната закрывается через минуту.

## Разработка

```bash
node server/server.js        # http://localhost:8080
node --test test/*.test.js   # тесты мира и сервера
```

Node 22+, зависимостей нет.

## Выпуск

1. После правки файлов в `public/` поднять `VERSION` в `public/core.js` и `public/sw.js` (тест сверяет) — иначе устройства останутся на старой версии из кэша, а сервер не пустит старый клиент в комнату.
2. Тег `vX.Y.Z` → GitHub Actions собирает `ghcr.io/zxibizz/snake-game:X.Y.Z`, Flux в кластере лаба подхватывает новый тег сам.

# Змейград

Змейки на арене для браузера: без рекламы, без сети, без внешних библиотек. Три уровня сложности:

- **Лёгкий:** добрые боты, после проигрыша можно продолжить с половиной длины, край арены отталкивает.
- **Средний:** одна жизнь, боты иногда подрезают.
- **Сложный:** одна жизнь, боты охотятся, окружают и ускоряются.

## Офлайн

Это PWA: `sw.js` при первом открытии кладёт все файлы в кэш.

1. Открыть сайт с интернетом.
2. iPad/iPhone: Safari → «Поделиться» → «На экран „Домой“». Android: Chrome → ⋮ → «Добавить на главный экран».
3. Один раз запустить с иконки при интернете и дождаться в меню «✅ Игра сохранена…».
4. Проверить в авиарежиме.

## Обновление

После правки любого файла увеличить `VERSION` в `sw.js` (и в `game.js` для подписи в меню), иначе устройства останутся на старой версии из кэша.

Локально: `python3 -m http.server` в корне репо.
